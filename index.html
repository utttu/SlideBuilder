Block types

statPanel — titled card with numeric rows and an optional note.

stage — numbered process step with trigger / responsible / actions. Variants: light, medium, bold, dark, success, warning.

bulletList — titled bullet list.

keyValueGrid — label/value pairs in 1 or 2 columns.

quote — pull quote with author.

noteBox — highlighted note callout (no card chrome).

heading — large headline (center / accent options).

image — image with optional caption.

html — raw HTML escape hatch.
